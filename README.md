## 🔧 Troubleshooting Common Issues

### Can't See the polymoly Icon
- Make sure the extension is enabled. Go to the Extensions panel (Ctrl+Shift+X), find polymoly, and check it's enabled.
- Restart VS Code.

### API Key Not Working
- Double-check you copied the entire key, including no extra spaces.
- Verify the key is valid by checking your account on the provider's website.

### Slow Responses
- Check your internet connection.
- Some providers can be slower at peak times. Try another agent.
